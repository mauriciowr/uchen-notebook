# Caderno de Uchen

Caderno para aprender a escrever o tibetano uchen: as 30 consoantes, vogais, letras sobrescritas e subscritas, mantras (Om Mani, Guru Rinpoche, Vajrakilaya) e cards de revisão.

- **App:** https://mauriciowr.github.io/uchen-notebook/
- Funciona offline depois da primeira abertura (service worker) e pode ser instalado na tela inicial.
- **⟳ Sincronizar** busca a versão nova e, com uma chave do GitHub (permissão só de gists), junta o progresso entre aparelhos numa gist privada.
